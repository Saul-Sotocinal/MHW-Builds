# Devlog :3
### No use of AI in this assignment.

## Approach

### Code Refactor

Firstly, I refactored how I was passing builds around to components because I didn't like having to pass both the builds array and its setter to every component in the app. I found out about Context hooks online, but I had trouble getting it to work. A stack overflow post helped me out which I credited in the code.

There was another issue I faced after where it was creating copies of the builds array, but I eventually found that the fix for that was that I had to wrap the BuildsContextProvider component I wrote around the entrypoint of the app instead of where I placed it originally and that fixed it.

I refactored most components to be more dynamic. for example the build cards and detiald build cards.

### CRUD Operations

#### Create

For creating builds, I added a button on the homepage which when pressed will create a new build based off of a default template build. It is then placed into the array and the user can click on it to edit it. I had issues with placing it in the correct spot when I was sorting and filtering the data, where it would always be placed at the end. This was fixed after refactoring.

#### Update

For updating builds, I made it so that when a user taps on a build it brings them to a separate screen of the app where they're able to change their build's equipment, and rename it by clicking on its name. To do this I had to change some of the UI code to use the Pressable component instead of the View component, but overall it wasn't too difficult.

#### Delete

For deleting builds, I just added a delete build button on the build edit page that deletes the build when pressed. I originally forgot to add a confirmation for deleting builds so I also did that a bit later.

### Navigation

For the routes, they did not end up looking like my initial plan much. I realized,the create screen was unnecessary. The edit page and Id detail page was the same. navigating back a page after deleting a build was probably the hardest part of the navigation but was generally easy, I think. :3
